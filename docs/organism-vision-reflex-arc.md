# TSA 有机体愿景：反射弧提案（拟 RFC-0030）

> 起源：领导 2026-09-12 裁决——「TSA 接入项目后给项目提供大脑🧠、血液、神经，
> 让整个项目像人体机制那样迅速跟大脑建立起联系」。
> 本文在原比喻基础上补全生理学映射与分级反射设计，给出可立项的工程路线。

## 一、领导的比喻 → TSA 实体对照

| 生理系统 | TSA 对应物 | 状态（2026-09-12） |
|---|---|---|
| 大脑🧠 | AST 索引 + synapse 解析器 + edges 图——项目对「谁是谁、谁连谁」的**知道** | ✅ 强（390× 差异化载体） |
| 血液 | 新鲜度循环：增量重索引、`certified_pulse_connection` 源码认证（大脑拒用过期血液）、内容戳（血相一变旧地图即刻作废，v1.32.0） | ✅ 本周接通 |
| 神经 | call/import graph 是神经纤维；`pulse` 即**脉搏**；hyphae watch/subscribe（RFC-0001 已实现、低使用）是传入神经 | ⚠️ 半接通 |
| 迅速建立联系 | 反射弧：文件一动 → 受影响符号上下文自动推到 agent 面前 | ❌ 缺口（本提案） |

## 二、我的扩展：把生理学映射补全

1. **分级反射（核心增量）**。人体有两套神经通路，TSA 也应该有：
   - **脊髓反射**（不经大脑、毫秒级）：文件保存 → 增量重索引 → 内容戳失效 →
     缓存作废。v1.32.0 的内容戳其实已经是第一根脊髓神经——它让「血液成分变了」
     这件事不需要任何 agent 询问就自动成立。
   - **皮层反射**（经大脑、按需）：agent 主动 `pulse` 查询。今天的 TSA 只有这一级。
   - 缺的是把脊髓信号**上传**为皮层通知：订阅者收到「你上次看过的符号，
     它的世界刚刚变了」。
2. **本体感觉（proprioception）**。健康的人不看腿也知道腿在哪。对应：项目不被
   查询也知道自己的连接状态。`iga=false` / `call_graph_available=false` 是
   「哑神经告示牌」（诚实但被动）；本体感觉是神经系统**主动报告**——
   订阅通道常驻推送图结构变化（新边、断边、热点迁移）。
3. **免疫记忆**。受伤过的部位下次反应更快：postmortem 知识、git heat 热区、
   `change-impact` 的风险记忆 → 同区域再次改动时警戒级别自动上调。
   （`health` 的 RFC-0025 self-proprioception 已在此方向上。）
4. **新陈代谢**。索引不是仓库是器官：旧条目衰减、重索引即细胞更新、
   `.ast-cache` 生命周期即代谢周期（index-lifecycle.md 已有基础）。
5. **睡眠巩固**。夜间全语言金测试 = 深睡巩固（REM）；日间增量验证 = 浅睡。
   已有 CI 节奏天然对应，缺的是把「昨夜巩固发现的问题」在今晨第一次
   连接时主动汇报（接入即体检报告）。
6. **出生即呼吸**。「接入当天秒通」的生理学翻译：克隆后第一条命令
   `autoindex + doctor + first pulse` 应在秒级完成并哭出声——
   返回一份「本项目神经分布图」（get_project_schema 的体验化）。

## 三、差距（诚实清单）

1. 今天是**体检式**（大脑逢器官必问），不是**生理式**（器官自己报）；
   hyphae 推送通道存在但没接成完整反射弧。
2. 神经没长全：Go/Rust/Java/C# 的 import 神经缺失（v1.32.0 只装了哑神经告示牌）。
3. 三套 import 解析引擎并行（import_graph / project_graph / synapse），
   神经纤维没有统一髓鞘。
4. main 分支实际无保护（AGENTS.md 声称有）——治理漂移，反射弧依赖的
   发布神经需要先修好。

## 四、路线图（每阶段可验收）

**Phase 0（已完成，v1.31.0/v1.32.0）**：心脏（pulse 稳定）、血型（源码认证）、
凝血（超限降级）、温血（内容戳缓存）。

**Phase 1 脊髓反射（建议先立项）**：
文件 watch → 增量重索引 → 戳失效 → hyphae 推送受影响符号摘要。
验收命令可写：`改动文件 X，订阅者在 ≤2s 内收到包含 X 受影响符号的推送`。
复用件：hyphae subscribe（已有）、ast_cache 增量（已有）、内容戳（已有）——
本质是把三根已存在的神经接成一条弧。

**Phase 2 神经延伸**：Go/Rust/Java import 边（synapse 语言件模式现成），
三引擎统一到 project_graph 的注册表之后再多处长神经。

**Phase 3 皮层整合**：跨会话记忆锚定索引世代（「我上次看时是 gen-42，
现在 gen-45，变了这三处」）——大脑的记忆与身体的发育对齐。

## 五、处置建议

- Phase 1 独立立项，走 feature 分支 + RFC 编号（拟 RFC-0030，需架构评审）。
- Phase 2 前先做三引擎收敛评估（审计文档已留观察）。
- 治理修补随 Phase 1 顺带：main 分支保护落地，或修正 AGENTS.md 的声称。
